# P20 Guten Gallery

Version 1.0.9. Requires WordPress 6.5 and PHP 7.4. Licensed under GPL-2.0-or-later.

1. Upload `guten-gallery.zip` through **Plugins → Add New Plugin → Upload Plugin**, then activate it.
2. Insert **Guten Gallery** in a post, page, or block theme template. Choose a layout and an image source in the block settings.
3. For a hand-picked gallery, use **Select or upload images** and drag images into order in the media dialog. For an automatic gallery, choose **Attached to current post**. This displays images whose attachment parent is that post. In a Query Loop, each gallery uses its corresponding post.
4. Adjust columns, gap, captions, and full-size image viewing in the block settings. Use the Styles panel for WordPress block styling.

The gallery uses WordPress media and has no external image service. Update discovery contacts GitHub. The **P20 Plugins → Guten Gallery** help page requires the [P20 Plugins companion](https://github.com/p20dev/wordpress/releases/download/p20-plugins-v1.0.1/p20-plugins.zip). Use the setup prompt or install the companion ZIP manually.
